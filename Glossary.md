# Ironwood Shopworks Trade Glossary

Cabinetry/woodworking terminology varies a lot shop to shop — the same part, tool, or step often
goes by several different names depending on where someone trained or who taught them. This
glossary exists to catch that: one canonical entry per concept, with every alternate name we've
heard attached to it, so an unfamiliar term during training (or on the job) can be looked up fast
instead of stalling understanding until it "clicks" in person.

This is cross-cutting by nature — it isn't filed under any one production stage, since the same
naming problem shows up everywhere from Bidding through Install.

## How to add an entry

- Pick the name to use as the canonical one — doesn't have to be "the most correct" version, just
  the one this glossary indexes everything else against.
- List every other name heard for the same thing under **Also called**.
- Write the description the way you'd explain it to someone about to see it in person — plain and
  concrete beats formal.
- Note which stage(s) it usually comes up in, if that's useful context.
