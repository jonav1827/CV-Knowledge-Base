There are four Filter Types you can choose in the Part Filter:
   1. New Filter - This option will not take into account any currently selected Parts or Previously Filtered Parts.
   2. Add to Selected Items - This option will build a Filter that will not de-select any Parts manually selected from the Parts View.
             For Example: If you enter the Filter Parts screen and select Room 1 and exit the Filter and upon entering the Parts View realize you also want Cabinet #2 in Room 2. You

               switch to "Filter On Previous Selection" then select my ¼ Material. The only items selected when I return to the Parts List would be the ¼ Material for Cabinets 1, 8, and 47.

     Export Report

The Export option allows you to Export the currently active Report to another Application or File for further modification. Finished reports can be exported to a number of popular
formats, such as spreadsheet, word processor, HTML, XML, and other common data interchange formats. This makes the distribution of information easier. For example, you may
want to use the report data to project trends in a spreadsheet package or to enhance the presentation of data in a desktop publishing package.
The exporting process requires you to specify a format via the Direct to... option.

Export Direct To... Types

The export formats supported by the Reports area can be broadly categorized in two groups: page-based formats and record-based formats. Page-based formats tend to produce a
more exact output. The emphasis of these formats is layout representation and formatting. Formatting refers to attributes such as font style, text color, text alignment, background
color, and so on. Layout refers to object position, object size, and the relationship between these attributes and other objects. Depending on the format of the Report, it may not be
possible for the program to preserve all layout and formatting perfectly, but page-based formats, in general, preserve these properties as closely as possible.
With record-based formats, the emphasis is on data rather than the layout and formatting. However, in some formats--such as Microsoft Excel - Data only--you will notice that
some formatting is exported.
Please consider:

     Due to the format, the layout cannot always be taken over 1:1 because there are specific restrictions when converting to these formats.

Part labels

All existing part label reports have indicators on each part label which indicate if a part will run in a "normal" or "mirror" part machining "zone" (M) and, also, if the part has two part
CNC programs (2nd):

How to "read" the M and 2nd indicators:

Part on label has one part CNC program (that which is referenced on the part label) that will run in a "normal" part machining "zone".

Part on label has one part CNC program (that which is referenced on the part label) that will run in a "mirror" part machining "zone".

Part on label has two part CNC programs. The part CNC program which is referenced on the part label itself will run in a "normal" part machining "zone." The second part CNC program
(referenced implicitly) will run in a "mirror" part machining "zone" (opposite of that indicated for part CNC program referenced on the part label).

Part on label has two part CNC programs. The part CNC program which is referenced on the part label itself will run in a "mirror" part machining "zone." The second part CNC program
(referenced implicitly) will run in a "normal" part machining "zone" (opposite of that indicated for part CNC program referenced on the part label).
