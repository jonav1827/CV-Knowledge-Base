The CVData.mdf File

The CVData.mdf file stores all primary data for CABINET VISION and the S2M CENTER.
The following is the breakdown of the tables and their fields:

Assembly

This table stores Catalog Objects.

Field                Description

ID                   A unique number to identify the record

AssemblyCatalogID    A cross reference to [AssemblyCatalog].[ID]

Name                 The name of the assembly.

Description          A description for the assembly.

ParentID             A reference number to the parent assembly if this object is part of a group

AliasOf              A reference number to the main assembly if this object has been cloned. Zero, if the object is a main assembly.

Height               The default height of the object. If the object is saved with the Preserve Size option selected it will come out of the library to the saved size. Otherwise, it will revert to the default height
                     for this object type.

Width                The default width of the object.

Depth                The default depth of the object. If the object is saved with the Preserve Size option selected it will come out of the library to the saved size. Otherwise, it will revert to the default depth
                     for this object type.

AssemblyClassTypeID  A cross reference to [refAssemblyClassType].[ID]

AssemblyUnitTypeID   A cross reference to [refAssemblyUnitType].[ID]

HingeLeft            A Boolean flag set true if assembly is hinged on the left/top

HingeRight           A Boolean flag set true if assembly is hinged on the right/bottom

AutoFill             A Boolean flag if set to true will use this object for automatically filling empty spaces on the wall with objects.

Weight               The weight of the object in kilograms - Used in many stock catalogs for pricing.
